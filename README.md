# Empty-Pockets
Is a game about the Great Depression
To play download and run Empty_Pockets.exe


Empty Pockets is built around a tile bases grid where you place:
Factories (Textile, Furniture, Oil, Food, Tools, and Steel),
Mines (Iron, Coal, Gold),
Connections that ove resouurrces between buildings,
There is a port(cyan tile) that will recieve and sell goods.

There are 3 levels the Tutorial, Pittsburg, and San Diego.
